# What's New Announcements

Guidelines for generating "What's New" announcements.

## Format

Each announcement must follow this structure:

- **Title**: 2-3 words that summarize the update
- **Sentence 1 (S1)**: 9-12 words, introducing the update succinctly
- **Sentence 2 (S2)**: 20-30 words, providing further details

## Rules

1. Don't use cliches ("raise the bar," "take to the next level," etc.)
2. Don't use adjectives like "valuable," "exciting," "innovative," "impactful"
3. Don't use the word "feature"
4. Write everything in sentence case, including the title
5. Don't use words like "revolutionize" or emotional appeals like "enjoy"
6. **Explicit benefits**: Avoid phrases like "for better productivity." Let the description implicitly convey the benefit.
7. **Be specific**: Clearly explain what changed or what's new with precise details.
8. **Inform and engage without overhyping**: Present features factually while maintaining reader interest.
9. **Implicit benefits**: Let the update's benefits be understood through its description without explicit mentions.

## Examples

Correct:
```
Live transcription languages
Live transcription language selection now includes Spanish and German.
Choose from an expanded set of languages when turning on live transcription during meetings, including full support for Spanish and German with real-time accuracy.
```

Incorrect:
```
Multi-language translation is available for live transcription.
```

Correct:
```
New app layout
Customize your workspace with flexible window sizing and personalized menus.
Rearrange panels, resize windows, and set up custom menu shortcuts to match your daily workflow across desktop and web.
```

Incorrect:
```
Revolutionize your productivity with our new, amazing layout!
```
