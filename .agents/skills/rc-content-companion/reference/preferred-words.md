# Preferred Words and Terminology

Always use these preferred terms. Avoid the deprecated alternatives listed.

## Admin Portal
Use instead of: "Service web"

## allow / let
Use "allow" or "let" instead of "permit" for authorizations.
- Correct: Allow panelists to join before the host. OR Let panelists join before the host.
- Incorrect: Permit panelists to join before the host.

## call history / call log
Use when referring to a list of past calls everywhere except Admin Portal.

## click / tap / press / enter / type
- **click**: desktop actions
- **tap**: mobile actions
- **press**: both mobile and desktop, or specific keyboard keys ("Press Enter/Return to insert a line break")
- **enter**: inputting information ("Enter a name or email address in the search bar")
- **type**: only to encourage filling out an empty field ("Start typing")

## computer
Use "computer" instead of "desktop," "device," or "laptop." For tablets and phones together, use "mobile devices."

## connect / pair
- **connect**: physically connecting things with a cord
- **pair**: wireless (e.g., Bluetooth) connections

## copy / duplicate
- **copy**: reproduction of an element of a whole (a meeting link, a meeting invite)
- **duplicate**: exact copy of a digital entity (an email, meeting, or webinar)

## coworker / user
- Use "coworkers" as primary. Use "teammate" (one word) for emphasis on familiarity or to avoid repetition.
- Reserve "users" for admin-specific contexts (service web, host portal, etc.).

## delete / remove
- **delete**: information is non-recoverable or action can't be reversed
- **remove**: information becomes invisible but still exists, or action can be reversed

## dropdown
- Noun/adjective: one word, no hyphen. Don't include "menu" after it.
- Verb: two words ("drop down")
- Correct: Choose the best answer from the dropdown
- Incorrect: Choose the best answer from the drop-down menu

## deskphone
Always one word. Use instead of "hardphone."

## dialpad
One word, not capitalized. RingCentral-specific name for the phone keypad.

## edit / change / update
- **edit**: partial change (modifying a user name, meeting detail). Don't use "modify."
- **change**: complete replacement (password, settings with predefined choices)
- **update**: making something more current (an app, a page, an invite)

## incoming / outgoing
Use instead of "inbound/outbound" when referring to calls (except in Admin Portal where existing terminology applies).

## invite
Use "invite" instead of "invitation" for electronic meeting invitations.
- Correct: Send invites to panelists
- Incorrect: Send invitations to panelists

## link
Use "link" instead of "URL."
- Correct: Copy and paste this link into your browser.

## OK / Close / Done / Dismiss / Got it
- **OK**: dismiss or close a message. Don't use when you can use the actual action verb. Never use "OKAY," "okay," or "Ok."
- **Done**: at the end of a multi-step process. Otherwise use OK.
- **Got it**: only in Pendo/WalkMe campaigns.
- **Close**: dismiss an element. Don't use "dismiss."

## screen share
- Noun (specific functionality): two words, no hyphen
- Participle: no hyphen ("Screen sharing requires...")
- Action: "share a/your/their screen"

## select / choose
- **select**: with nouns, choosing from a list or clicking a specific button ("Select all fields that apply")
- **choose**: all other instances ("Choose how to join")

## sign in
Use "sign in" not "log in." Use "on" preposition when specifying the app: "Sign in on the RingCentral desktop app."

## SMS vs text
1. Use "text" and derivations (texting, send a text, text messaging) for functionality that includes both SMS and MMS.
2. Use "SMS" only when:
   - The functionality is limited to standard short text messages via cellular carriers
   - Referring to an official RingCentral product name (e.g., RingCentral Business SMS)
3. "Send a text message" to avoid confusion. When context is clear, shorter "text" is fine.
4. In space-constrained mobile contexts, "Send a text" is acceptable.

## speaker / speakers
- Singular for mobile phone audio equipment
- Plural for desktop audio equipment
- Singular in compounds: "speaker cable"

## transfer
Use "transfer" not "port" when referring to a phone number.

## turn on / turn off
Use in toggles instead of "enable/disable."

## update / upgrade
- **update**: new version of the app or software/OS versions
- **upgrade**: major software/OS changes, paid improvements, license tiers

## watch / view
Use "watch" as default. Use "view" to avoid repetition.

## WiFi
Use "WiFi." Not "wifi," "Wifi," or "Wi-Fi."

## ZIP Code
Use "ZIP Code." Not "Zip code" or "ZIP code."
