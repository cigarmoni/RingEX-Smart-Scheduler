# Squircle

Squircle shape container

## Import

```tsx
import { Squircle } from '@ringcentral/spring-ui';
```

## Props

### `focusVisible`

**Type**: `boolean`

### `active`

**Type**: `boolean`

### `interactive`

**Type**: `boolean`

**Default**: `true`

### `fillShape`

**Type**: `boolean`

### `classes`

**Type**: `ClassesOverride`

Override or extend the styles applied to the component

**Available keys**: `"root"`, `"interactive"`, `"content"`, `"ring"`

### `component`

**Type**: `"div"`

The component used for the root node.
Either a string to use a HTML element or a component.
