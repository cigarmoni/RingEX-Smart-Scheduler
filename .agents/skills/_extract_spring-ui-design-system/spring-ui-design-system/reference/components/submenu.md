# SubMenu

Nested submenu

## Import

```tsx
import { SubMenu } from '@ringcentral/spring-ui';
```

## Props

### `itemContent`

**Type**: `ReactNode`

### `classes`

**Type**: `ClassesOverride`

Override or extend the styles applied to the component

### `id`

**Type**: `string`

### `onClick`

**Type**: `MouseEventHandler<any>`

### `focused`

**Type**: `boolean`

If not undefined, shows the focused state of the item by default.

**Default**: `undefined`

### `disabled`

**Type**: `boolean`

### `selected`

**Type**: `boolean`

If not undefined, apply selectable styling.

**Default**: `undefined`

### `autoFocus`

**Type**: `boolean`

Auto focus item when mounted.

### `disableFocusOnHover`

**Type**: `boolean`

If `true`, the menu item won't receive focus when the mouse moves over it.

**Default**: `false`

### `highlighted`

**Type**: `boolean`

If not undefined, shows the hover state of the item by default.

**Default**: `undefined`

### `autoClose`

**Type**: `boolean`

Auto close menu after click item.

**Default**: `true`
