# DragHandle

Handle for draggable items

## Import

```tsx
import { DragHandle } from '@ringcentral/spring-ui';
```

## Props

### `anchor`

**Type**: `"top" | "bottom"`

The anchor position to determine handle orientation

**Default**: `'top'`

**Options**: `"top"`, `"bottom"`

### `classes`

**Type**: `ClassesOverride`

Override or extend the styles applied to the component

**Available keys**: `"root"`, `"bar"`, `"top"`, `"bottom"`

### `component`

**Type**: `"div"`

The component used for the root node.
Either a string to use a HTML element or a component.
