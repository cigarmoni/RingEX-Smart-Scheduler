# TableHead

Table header section

## Import

```tsx
import { TableHead } from '@ringcentral/spring-ui';
```

## Props

### `children`

**Type**: `ReactNode`

The content of the component, normally `TableRow`.

### `useDefaultBgColor`

**Type**: `boolean`

Use default table background color.

### `classes`

**Type**: `ClassesOverride`

Override or extend the styles applied to the component

**Available keys**: `"root"`, `"background"`, `"title"`, `"end-slot"`, `"sticky"`, `"divider"`

### `component`

**Type**: `"thead"`

The component used for the root node.
Either a string to use a HTML element or a component.
