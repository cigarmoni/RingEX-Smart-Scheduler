# MenuHeader

Header for menu sections

## Import

```tsx
import { MenuHeader } from '@ringcentral/spring-ui';
```

## Props

### `classes`

**Type**: `ClassesOverride`

Override or extend the styles applied to the component

**Available keys**: `"root"`, `"title"`, `"start"`, `"end"`

### `start`

**Type**: `ReactNode`

Start slot for putting an IconButton

### `end`

**Type**: `ReactNode`

End slot for putting a IconButton

### `divider`

**Type**: `boolean`

If true, show divider

**Default**: `true`
