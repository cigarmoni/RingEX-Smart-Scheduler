# StatusIndicator

Status indicator dot

## Import

```tsx
import { StatusIndicator } from '@ringcentral/spring-ui';
```

## Props

### `classes`

**Type**: `ClassesOverride`

Override or extend the styles applied to the component

**Available keys**: `"root"`, `"large"`, `"small"`, `"medium"`, `"dnd"`, `"busy"`, `"available"`, `"unavailable"`

### `size`

**Type**: `"small" | "large" | "medium"`

The size of the component.

**Default**: `'medium'`

**Options**: `"small"`, `"large"`, `"medium"`

### `variant`

**Type**: `"dnd" | "busy" | "available" | "unavailable"`

The variant of the component.

**Default**: `'available'`

**Options**: `"dnd"`, `"busy"`, `"available"`, `"unavailable"`
