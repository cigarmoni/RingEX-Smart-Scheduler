# PageHeader

Page header container

## Import

```tsx
import { PageHeader } from '@ringcentral/spring-ui';
```

## Props

### `classes`

**Type**: `ClassesOverride`

Override or extend the styles applied to the component

**Available keys**: `"root"`, `"integrated"`, `"detached"`

### `variant`

**Type**: `"integrated" | "detached"`

The variant to use.

**Default**: `'integrated'`

**Options**: `"integrated"`, `"detached"`
