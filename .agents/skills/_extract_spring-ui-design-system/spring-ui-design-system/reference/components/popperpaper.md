# PopperPaper

Paper container for popper

## Import

```tsx
import { PopperPaper } from '@ringcentral/spring-ui';
```

## Props

### `classes`

**Type**: `ClassesOverride`

Override or extend the styles applied to the component

**Available keys**: `"root"`, `"arrow"`, `"content"`

### `arrowRef`

**Type**: `Ref<HTMLDivElement>`

### `contentRef`

**Type**: `Ref<HTMLDivElement>`

### `arrowStyle`

**Type**: `CSSProperties`

### `motionProps`

**Type**: `MotionProps`

Override the motion applied to the component
