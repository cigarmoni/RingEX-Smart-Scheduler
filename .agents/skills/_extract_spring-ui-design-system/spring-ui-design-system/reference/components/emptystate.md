# EmptyState

Empty state placeholder

## Import

```tsx
import { EmptyState } from '@ringcentral/spring-ui';
```

## Props

### `classes`

**Type**: `ClassesOverride`

Override or extend the styles applied to the component

**Available keys**: `"root"`, `"icon"`, `"text-container"`, `"title"`, `"description"`, `"actions"`

### `icon`

**Type**: `ComponentType<{}>`

The icon to display at the top of the component.

### `title`

**Type**: `ReactNode`

The title to display.

### `description`

**Type**: `ReactNode`

The description to display.

### `actions`

**Type**: `ReactNode[]`

The actions to display at the bottom of the component.
