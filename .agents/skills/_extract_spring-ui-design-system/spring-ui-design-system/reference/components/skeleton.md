# Skeleton

Loading skeleton placeholder

## Import

```tsx
import { Skeleton } from '@ringcentral/spring-ui';
```

## Props

### `classes`

**Type**: `ClassesOverride`

Override or extend the styles applied to the component

**Available keys**: `"root"`, `"circular"`, `"squircle"`, `"rectangular"`, `"text"`

### `variant`

**Type**: `"text" | "circular" | "squircle" | "rectangular"`

Sets the variant of the component.

**Options**: `"text"`, `"circular"`, `"squircle"`, `"rectangular"`
