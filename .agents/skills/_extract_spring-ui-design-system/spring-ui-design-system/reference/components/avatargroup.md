# AvatarGroup

Group of avatars

## Import

```tsx
import { AvatarGroup } from '@ringcentral/spring-ui';
```

## Props

### `children`

**Type**: `ReactNode`

You can only pass 2 Avatar components as children

### `classes`

**Type**: `ClassesOverride`

Override or extend the styles applied to the component

**Available keys**: `"root"`, `"item"`

### `component`

**Type**: `"div"`

The component used for the root node.
Either a string to use a HTML element or a component.
