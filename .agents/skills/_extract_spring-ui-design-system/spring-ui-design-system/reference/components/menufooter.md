# MenuFooter

Footer for menus

## Import

```tsx
import { MenuFooter } from '@ringcentral/spring-ui';
```

## Props

### `classes`

**Type**: `ClassesOverride`

Override or extend the styles applied to the component

**Available keys**: `"root"`

### `divider`

**Type**: `boolean`

If true, show divider

**Default**: `true`
