# BlockHeader

Header for block components

## Import

```tsx
import { BlockHeader } from '@ringcentral/spring-ui';
```

## Props

### `endSlot`

**Type**: `ReactNode`

End slot of this header.

### `divider`

**Type**: `boolean`

If true, show blockHeader divider

**Default**: `false`

### `classes`

**Type**: `ClassesOverride`

Override or extend the styles applied to the component

**Available keys**: `"root"`, `"title"`, `"end-slot"`, `"divider"`

### `component`

**Type**: `"div"`

The component used for the root node.
Either a string to use a HTML element or a component.
