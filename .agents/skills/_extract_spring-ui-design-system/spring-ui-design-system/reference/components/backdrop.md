# Backdrop

Modal backdrop overlay

## Import

```tsx
import { Backdrop } from '@ringcentral/spring-ui';
```

## Props

### `classes`

**Type**: `ClassesOverride`

Override or extend the styles applied to the component

**Available keys**: `"root"`, `"transparent"`

### `isTransparent`

**Type**: `boolean`

Prop to set backdrop transparent

**Default**: `false`
