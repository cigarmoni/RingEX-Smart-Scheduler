# Spring UI Icons

Complete reference for all 558 Spring UI icons from `@ringcentral/spring-icon`.

## Import

```tsx
import { IconName } from '@ringcentral/spring-icon';
```

## Usage

### With Icon Component
```tsx
<Icon symbol={IconName} size="medium" />
```

### With IconButton
```tsx
<IconButton symbol={IconName} />
```

### With Button
```tsx
<Button startIcon={IconName}>Label</Button>
```

## Icon Sizes

- `xsmall` - 12px
- `small` - 16px
- `medium` - 20px (default)
- `large` - 24px
- `xlarge` - 32px
- `xxlarge` - 36px
- `xxxlarge` - 40px
